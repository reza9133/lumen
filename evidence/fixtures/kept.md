# Lumen fixture changelog

This page is evidence for the live end-to-end run of the Lumen contract. It is a plain text page on purpose, so
that the validators can read it the same way on every run.

## Release 2.0.0

The release 2.0.0 entry of the Lumen fixture changelog was published on 2026-01-15.

The entry lists three changes: vows can be retracted before anyone backs them, keepers can post progress notes,
and the contract serves an activity feed with a keeper directory.
